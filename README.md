**Worth a look**

- [dotenvup](https://github.com/sarhej/dotenvup) ([dotenvup.com](https://dotenvup.com)): encrypted `.env` format, so secret values stay encrypted in the repo and in AI coding agents' context. X25519 + XChaCha20-Poly1305. VS Code/Cursor extension, CLI, MCP server, Claude Code plugin. MIT.
- [RemoteKit](https://remotekit.ai): drive a coding agent on your own Mac from phone or browser. Code stays on the machine; the relay sees only ciphertext. Signed and notarized Mac app.
- [UnknownPassword](https://unknownpassword.com): zero-knowledge secret sharing. AES-256-GCM in the browser, burn-after-read, GitHub-identity recipient lock. Architecture notes: [unknownpassword-zero-trust-architecture](https://github.com/sarhej/unknownpassword-zero-trust-architecture).
- [claude-fix](https://github.com/sarhej/claude-fix): run multiple Claude Desktop accounts on one Mac. Isolated work, personal and client profiles via separate launcher apps. Homebrew tap, integration tests in CI. MIT.
- [Tymio](https://tymio.app): multi-tenant product management hub with an OAuth-secured MCP server for AI agents. I run all my projects on it.
- [vg-stc2000-macos](https://github.com/sarhej/vg-stc2000-macos): an abandoned Samsung TV camera used as a UVC webcam and microphone on macOS. Firmware loader ported from the Linux original by ondrej-zary.
